# Test Plan

## Automated unit tests

Run `python -m unittest discover -s tests -v`. The test suite covers eligible and ineligible paths, amount-cap handling, boundary tenures, joint ownership, out-of-order answers, multiple facts in one utterance, same-utterance corrections, identity privacy, busy/callback behavior, transfer routing, interest-rate diversion, and the mandatory final handoff gate.

## Scenario runner

Run `python examples/run_scenarios.py`. It exercises 15 simulated customer conversations and writes:

- `outputs/scenario_results.json` — expected/actual results and state snapshots.
- `outputs/scenario_transcripts.md` — text transcripts for review.

These outputs are marked **simulated**; they are not actual voice-platform audio recordings or call logs.

## Hosted voice-platform manual matrix

After pasting the system prompt into the hosted platform, run these scenarios and inspect actual audio, transcript, call log, and final disposition:

| Scenario | Expected outcome |
|---|---|
| Happy path | Preliminary qualification only after all seven checklist items |
| Agricultural property | Immediate polite disqualification and call end |
| Joint ownership | Continue; never reject solely for joint ownership |
| Missing originals | Immediate disqualification |
| Cash or mixed cash/bank income | Immediate disqualification |
| Tenure 2 / 16 years | Immediate disqualification |
| Tenure 3 / 15 years | Accept boundary values |
| Loan ₹90 lakh, then accepts ₹75 lakh | Ask cap question; proceed only after acceptance |
| Loan ₹90 lakh, then declines ₹75 lakh | End without asking remaining eligibility questions |
| Existing property loan | Specialist message and end |
| EMI reduction | Specialist message and end |
| Busy customer | Ask callback preference, record it, then end |
| Out-of-order details | Store all recognized facts; ask only earliest missing item |
| Correction: “10 years—actually, 12” | Latest clear answer wins if call has not already terminated |
| Interest-rate diversion | Do not invent a rate; return to pending question |
| Wrong person | End without revealing offer |
| Ambiguous documents | Clarify; do not infer availability |
| Unknown market value | Note unknown; do not invent threshold |

## Final submission evidence

1. `prompts/system_prompt.md` or the exact prompt pasted into the hosted platform.
2. A public share link to an **actual** hosted voice-platform call recording and call log.
3. Actual audio recordings and transcripts for the tested scenarios.
4. Optionally, this approach/architecture document and automated test output.

The actual recording/log URL must be generated by the voice platform account; this repository cannot manufacture a genuine hosted call recording.
