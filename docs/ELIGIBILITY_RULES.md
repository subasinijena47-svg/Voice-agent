# Eligibility Rules and Boundary Cases

| Field | Accepted value | Invalid value / behavior |
|---|---|---|
| Property type | Residential, commercial, industrial | Agricultural → `NOT_ELIGIBLE`, end immediately |
| Ownership | Sole, joint | Both accepted |
| Original documents | Available for verification; may be safely kept at home | Only photocopies / unavailable → `NOT_ELIGIBLE`, end immediately |
| Loan amount | Requested amount up to and including ₹75,00,000 | Above ₹75,00,000 → ask if ₹75,00,000 or a clearly selected lower amount works; end if declined |
| Occupation | Salaried or self-employed | Both accepted |
| Income mode | Bank | Cash or mixed cash/bank income → `NOT_ELIGIBLE` |
| Market value | Capture an estimate, or note inability to estimate | **No minimum value is specified**; do not invent one |
| Tenure | 3–15 years inclusive | Below 3 or above 15 → `NOT_ELIGIBLE` |

## Required checklist order

1. Property type
2. Ownership
3. Original-document availability
4. Loan amount
5. Occupation **and** income mode (one checklist item, two fields)
6. Market value
7. Tenure

Questions are asked in this order, but facts may arrive out of order. Store all clear facts and ask only the earliest missing item. Any clear disqualification at any point ends the normal flow immediately. An existing property loan or EMI-reduction request uses the specialist path, not the fresh-loan checklist.

## Ambiguous cases

- “The original papers are probably somewhere” → clarify; do not assume availability.
- “I don't have them with me, but they're at home” → originals are available; physical possession during the call is not required.
- “Part of my income comes in cash and part through the bank” → disqualify because income must be received via bank.
- “Cash—sorry, actually, it goes into my bank account” → use the latest clear correction in the same utterance.
- “My property is worth ₹8 lakh” → record the estimate; no minimum threshold was provided.
- “I need ₹90 lakh” → ask whether ₹75 lakh will work; do not automatically reject.
